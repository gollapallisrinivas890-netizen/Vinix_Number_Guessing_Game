\# VINIX GUESS – Number Guessing Game



\## Project Overview

VINIX GUESS is a Python-based web application where players try to guess a randomly generated number between 1 and 100. The application provides hints, tracks attempts and rewards players with scores based on difficulty level.



\## Features

\- Random number generation

\- Easy, Medium and Hard levels

\- Player name validation

\- Guess checking and hints

\- Limited attempts

\- Score calculation

\- SQLite database integration

\- Leaderboard

\- Responsive UI design

\- Restart functionality



\## Technologies Used

\- Python

\- Flask

\- HTML5

\- CSS3

\- JavaScript

\- SQLite



\## Project Structure

\- app.py – Python backend

\- templates/index.html – HTML interface

\- static/style.css – Styling

\- static/script.js – Frontend logic

\- instance/game.db – Database



\## How to Run

1\. Install Python.

2\. Install Flask using `pip install flask`.

3\. Run `python app.py`.

4\. Open http://127.0.0.1:5000 in your browser.
